# Roadmap / 开发路线

## Phase 1: Documentation and Planning / 文档和规划

Create README and planning documents, define feature scope, privacy boundaries, screen list and data model.

创建 README 和规划文档，明确功能范围、隐私边界、页面列表和数据模型。

Status: current phase.

状态：当前阶段。

## Phase 2: Basic Expo Project Setup / 基础 Expo 项目

Create an Expo + React Native + TypeScript project, add basic folder structure and decide the local storage approach.

创建 Expo + React Native + TypeScript 项目，整理基础目录结构，并确定本地存储方案。

## Phase 3: Static Screens and Navigation / 静态页面和导航

Build static screens for Home, Checklist, Documents, Travel, Budget, Emergency Contacts, Search and Settings. Add navigation before connecting real data.

先完成 Home、Checklist、Documents、Travel、Budget、Emergency Contacts、Search 和 Settings 静态页面，并在接入真实数据前完成导航。

## Phase 4: Local Storage and CRUD / 本地存储和增删改查

Implement create, read, update and delete flows for checklist items, documents, trips, budget records and contacts.

为生活事项、文件、旅行、预算和联系人实现新增、查看、编辑和删除。

## Phase 5: File Upload / Image Picker / 文件上传和图片选择

Add local file or image picker support for document records and travel files. Demo data must use fake files only.

为文件记录和旅行材料加入本地文件或图片选择功能。demo 数据必须使用虚拟文件。

## Phase 6: Search and Language Switching / 搜索和语言切换

Implement global search and English / Chinese interface switching.

实现全局搜索和中英文界面切换。

## Phase 7: GitHub Presentation / GitHub 展示完善

Polish README, add screenshots from demo data, check privacy notes and make the repository ready for portfolio presentation.

整理 README，使用虚拟数据补充截图，复查隐私说明，让仓库适合作品集展示。
