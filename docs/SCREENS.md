# Screens / 页面规划

This document describes the planned screens for the mobile app prototype. It focuses on simple navigation and clear user tasks.

本文档说明手机端 App 原型的页面规划，重点是简单导航和清楚的用户操作。

## Navigation Overview / 导航概览

Suggested main tabs:

- Home
- Checklist
- Documents
- Travel
- Budget

Search, Emergency Contacts, and Settings / Language can be opened from Home or a utility menu.

建议主导航包含：

- 首页
- 清单
- 文件
- 旅行
- 预算

搜索、紧急联系方式和设置 / 语言可以从首页或工具入口进入。

## Home / 首页

What it shows:

- Checklist progress.
- Document preparation status.
- Monthly budget summary.
- Upcoming trip summary.
- Recent files.
- Emergency contact shortcut.

Main actions:

- Open major modules.
- Open search.
- Open emergency contacts.

Navigation:

- Main entry screen.
- Links to Checklist, Documents, Travel, Budget, Search, and Emergency Contacts.

页面显示：

- 生活事项完成情况。
- 文件准备状态。
- 本月预算概览。
- 即将到来的旅行。
- 最近文件。
- 紧急联系方式入口。

用户可以做什么：

- 进入主要模块。
- 打开搜索。
- 打开紧急联系方式。

如何跳转：

- 作为 App 主要入口。
- 跳转到清单、文件、旅行、预算、搜索和紧急联系人页面。

## Checklist / 生活事项清单

What it shows:

- Checklist items.
- Status labels.
- Category filters.
- Notes preview when available.

Main actions:

- Add, edit, delete, and update item status.
- Filter by category.

Navigation:

- Opened from Home or main tabs.
- Add/edit may use a modal or simple edit screen.

页面显示：

- 生活事项列表。
- 状态标签。
- 分类筛选。
- 备注预览。

用户可以做什么：

- 新增、编辑、删除事项。
- 修改事项状态。
- 按分类筛选。

如何跳转：

- 从首页或主导航进入。
- 新增/编辑可以使用弹窗或简单编辑页。

## Documents / 文件列表

What it shows:

- Document records.
- Category.
- Expiry date if available.
- File preview or file name when available.

Main actions:

- Add document.
- Open document detail.
- Filter or search documents.

Navigation:

- Opened from Home or main tabs.
- Tapping a document opens Document Detail.

页面显示：

- 文件记录列表。
- 文件分类。
- 到期日期。
- 文件预览或文件名。

用户可以做什么：

- 新增文件。
- 打开文件详情。
- 筛选或搜索文件。

如何跳转：

- 从首页或主导航进入。
- 点击文件进入文件详情页。

## Document Detail / 文件详情

What it shows:

- Title.
- Category.
- Expiry date.
- Notes.
- Uploaded local file preview or file information.

Main actions:

- Edit document.
- Delete document.
- Open preview if supported.

Navigation:

- Back to Documents.
- Edit opens Add / Edit Document.

页面显示：

- 文件名称。
- 文件分类。
- 到期日期。
- 备注。
- 已上传的本地文件预览或文件信息。

用户可以做什么：

- 编辑文件。
- 删除文件。
- 在支持时查看预览。

如何跳转：

- 返回文件列表。
- 点击编辑进入新增 / 编辑文件页。

## Add / Edit Document / 新增或编辑文件

What it shows:

- Title input.
- Category picker.
- Expiry date input.
- Notes input.
- Local file or image picker.

Main actions:

- Save document.
- Cancel changes.
- Attach or replace local file reference.

Navigation:

- Opened from Documents or Document Detail.
- Returns to the previous document screen after save or cancel.

页面显示：

- 文件名称输入。
- 分类选择。
- 到期日期输入。
- 备注输入。
- 本地文件或图片选择入口。

用户可以做什么：

- 保存文件记录。
- 取消修改。
- 添加或替换本地文件引用。

如何跳转：

- 从文件列表或文件详情进入。
- 保存或取消后返回上一层文件页面。

## Travel / 旅行列表

What it shows:

- Trip list.
- Destination.
- Date range.
- Checklist progress.
- Saved file count.

Main actions:

- Add trip.
- Open trip detail.
- Delete trip if needed.

Navigation:

- Opened from Home or main tabs.
- Tapping a trip opens Travel Detail.

页面显示：

- 旅行列表。
- 目的地。
- 日期范围。
- Checklist 进度。
- 已保存文件数量。

用户可以做什么：

- 新增旅行。
- 打开旅行详情。
- 删除旅行。

如何跳转：

- 从首页或主导航进入。
- 点击旅行进入旅行详情页。

## Travel Detail / 旅行详情

What it shows:

- Trip name.
- Destination.
- Date range.
- Notes.
- Uploaded travel files.
- Trip checklist.

Main actions:

- Edit trip.
- Delete trip.
- Add or remove travel files.
- Add, edit, delete, and complete checklist items.

Navigation:

- Back to Travel.
- Edit opens Add / Edit Trip.

页面显示：

- 旅行名称。
- 目的地。
- 日期范围。
- 备注。
- 已上传的旅行文件。
- 该旅行的 checklist。

用户可以做什么：

- 编辑旅行。
- 删除旅行。
- 新增或移除旅行文件。
- 新增、编辑、删除和勾选 checklist。

如何跳转：

- 返回旅行列表。
- 点击编辑进入新增 / 编辑旅行页。

## Add / Edit Trip / 新增或编辑旅行

What it shows:

- Trip name input.
- Destination input.
- Start date and end date inputs.
- Notes input.

Main actions:

- Save trip.
- Cancel changes.

Navigation:

- Opened from Travel or Travel Detail.
- Returns to the previous travel screen after save or cancel.

页面显示：

- 旅行名称输入。
- 目的地输入。
- 开始日期和结束日期输入。
- 备注输入。

用户可以做什么：

- 保存旅行。
- 取消修改。

如何跳转：

- 从旅行列表或旅行详情进入。
- 保存或取消后返回上一层旅行页面。

- Expense list.
- Category summary.

Main actions:

页面显示：

用户可以做什么：

## Emergency Contacts / 紧急联系方式

What it shows:

- Contact list.
- Contact category.
- Phone number.
- Email.
- Notes.

Main actions:

- Add, edit, and delete contacts.
- Copy phone number or email.

Navigation:

- Opened from Home, Search, or a utility menu.

页面显示：

- 联系人列表。
- 联系人分类。
- 电话号码。
- 邮箱。
- 备注。

用户可以做什么：

- 新增、编辑、删除联系人。
- 复制电话号码或邮箱。

如何跳转：

- 从首页、搜索结果或工具入口进入。

## Search / 搜索

What it shows:

- Search input.
- Grouped results.
- Result type labels.

Main actions:

- Search local records.
- Open a result when a detail page exists.
- Clear search query.

Navigation:

- Opened from Home or a global search button.
- Results navigate to related screens.

页面显示：

- 搜索输入框。
- 分组结果。
- 结果类型标签。

用户可以做什么：

- 搜索本地记录。
- 打开可跳转的结果。
- 清空搜索内容。

如何跳转：

- 从首页或全局搜索按钮进入。
- 搜索结果跳转到对应页面。

页面显示：

用户可以做什么：

- 在英文和中文之间切换。
- 查看隐私说明。

如何跳转：

- 从首页或工具入口进入。
