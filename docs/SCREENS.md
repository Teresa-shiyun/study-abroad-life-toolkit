# Screens / 页面规划

## Home / 首页

Shows unfinished checklist count, missing document count, monthly budget usage, upcoming trips, recently added files and emergency contact shortcut.

展示未完成事项数量、未准备文件数量、本月预算使用情况、即将到来的旅行、最近添加的文件和紧急联系方式入口。

Navigation: links to Checklist, Documents, Travel, Budget and Emergency Contacts.

导航：可以进入 Checklist、Documents、Travel、Budget 和 Emergency Contacts。

## Checklist / 生活事项

Shows checklist items grouped or filtered by category and status.

展示按分类或状态筛选的生活事项。

Actions: add, edit, delete and change status.

操作：新增、编辑、删除和修改状态。

## Documents / 重要文件

Shows document records by category, with expiry dates and file preview indicators.

展示按分类整理的重要文件记录，包括到期日期和是否有文件预览。

Actions: add document, open document detail, search or filter by category.

操作：新增文件、打开文件详情、搜索或按分类筛选。

## Document Detail / 文件详情

Shows one document's name, category, notes, expiry date and local file preview.

展示单个文件的名称、分类、备注、到期日期和本地文件预览。

Actions: edit, delete or open file preview.

操作：编辑、删除或查看文件预览。

## Add / Edit Document / 新增或编辑文件

Form for document name, category, expiry date, notes and local file attachment.

用于填写文件名称、分类、到期日期、备注和本地文件附件。

Navigation: opens from Documents or Document Detail, returns after save or cancel.

导航：从文件列表或文件详情进入，保存或取消后返回。

## Travel / 旅行

Shows upcoming and past trips with destination and date range.

展示即将到来和过去的旅行，包括目的地和日期范围。

Actions: add trip, open trip detail, search trips.

操作：新增旅行、打开旅行详情、搜索旅行。

## Travel Detail / 旅行详情

Shows trip notes, uploaded travel files and the trip checklist.

展示旅行备注、上传的旅行文件和旅行 checklist。

Actions: edit trip, add files, edit checklist items, mark checklist items done.

操作：编辑旅行、添加文件、编辑 checklist、勾选已完成事项。

## Add / Edit Trip / 新增或编辑旅行

Form for trip name, destination, start date, end date and notes.

用于填写旅行名称、目的地、开始日期、结束日期和备注。

Navigation: opens from Travel or Travel Detail.

导航：从旅行列表或旅行详情进入。

## Budget / 预算

Shows monthly budget, spent amount, remaining amount and category summary.

展示月度预算、已花费金额、剩余金额和分类统计。

Actions: add, edit and delete spending records; set monthly budget.

操作：新增、编辑和删除支出记录；设置月度预算。

## Emergency Contacts / 紧急联系方式

Shows important contacts grouped by type.

展示按类型分组的重要联系人。

Actions: add, edit, delete and copy phone or email.

操作：新增、编辑、删除，并复制电话或邮箱。

## Search / 搜索

Shows search results across documents, checklist items, trips, budget records, contacts and notes.

展示来自文件、事项、旅行、预算、联系人和备注的搜索结果。

Actions: open the matched item and continue navigation from its detail screen.

操作：打开匹配结果，并从详情页继续导航。

## Settings / Language / 设置与语言

Shows language switch and simple app preferences.

展示语言切换和基础 App 偏好设置。

Actions: switch between English and Chinese.

操作：在英文和中文界面之间切换。
