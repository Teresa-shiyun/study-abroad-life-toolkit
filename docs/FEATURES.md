# Features / 功能说明

## First-Version Features / 第一版功能

### Home Dashboard / 首页总览

The dashboard gives a quick overview of unfinished tasks, missing documents, monthly budget usage, upcoming trips, recently added files and emergency contact access.

首页用于展示当前生活管理状态，包括未完成事项、缺失文件、本月预算使用情况、即将到来的旅行、最近添加的文件和紧急联系方式入口。

### Life Checklist / 生活事项清单

Users can create, edit and delete checklist items. Each item can be marked as `Not Started`, `In Progress` or `Done`, and filtered by category.

用户可以新增、编辑和删除生活事项。每个事项可以设置为 `Not Started`、`In Progress` 或 `Done`，也可以按分类筛选。

Default categories include Banking, Health, Housing, University and Travel.

默认分类包括 Banking、Health、Housing、University 和 Travel。

### Document Wallet / 重要文件夹

Users can add document records, attach a local image or file, edit category and notes, set an expiry date, preview uploaded files and delete records.

用户可以添加文件记录、关联本地图片或文件、编辑分类和备注、设置到期日期、预览已上传文件，并删除记录。

First-version document types include Passport, Visa / eVisa / BRP, Bank Letter, University Letter, CAS, Tenancy Agreement, Travel Insurance and Student ID.

第一版文件类型包括护照、签证 / eVisa / BRP、银行信、学校信、CAS、租房合同、旅行保险和学生证。

### Travel Wallet / 旅行材料管理

Users can create trips, edit trip details, upload travel-related files, view each trip's file list and manage a trip checklist.

用户可以新增旅行、编辑旅行信息、上传旅行相关文件、查看每次旅行的文件列表，并管理旅行 checklist。

### Budget Tracker / 生活预算记录

Users can add, edit and delete spending records, set a monthly budget, view spent and remaining amounts, and group spending by category.

用户可以添加、编辑和删除支出记录，设置每月预算，查看已花费和剩余金额，并按分类统计支出。

### Emergency Contacts / 紧急联系方式

Users can create, edit and delete important contacts, then copy phone numbers or emails quickly.

用户可以新增、编辑和删除重要联系人，并快速复制电话号码或邮箱。

### Search / 搜索

Search is planned across document names, checklist items, trip names, budget records, emergency contacts and notes.

搜索功能计划覆盖文件名称、checklist 事项、旅行名称、预算记录、紧急联系人和备注内容。

### Language / 中英文切换

The first version plans to support English and Chinese for main screens, buttons and category names.

第一版计划支持英文和中文界面，主要页面、按钮和分类名称都应可以切换。
