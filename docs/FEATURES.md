# Features / 功能规划

This document lists the planned features for the first version of Study Abroad Life Toolkit.

本文档整理海外留学生活助手第一版计划包含的功能。

## First Version Summary / 第一版概览

The first version should be a local-first mobile app prototype for organizing study-abroad life information. It should support basic create, edit, delete, view, search, and language switching flows where needed.

第一版应是一个本地优先的手机端 App 原型，用来整理留学生活信息。需要支持必要的新增、编辑、删除、查看、搜索和中英切换流程。

## 1. Home Dashboard / 首页总览

Shows:

- Unfinished life checklist count.
- Missing or incomplete document count.
- Monthly budget status.
- Upcoming trip summary.
- Recent documents or travel files.
- Emergency contact shortcut.

Main actions:

- Open checklist, documents, travel, budget, emergency contacts, or search.

页面显示：

- 未完成生活事项数量。
- 未准备或未完善的重要文件数量。
- 本月预算使用情况。
- 即将到来的旅行。
- 最近添加的文件或旅行材料。
- 紧急联系方式入口。

主要操作：

- 进入清单、文件、旅行、预算、紧急联系人或搜索页面。

## 2. Life Checklist / 生活事项清单

Purpose: manage common study-abroad life tasks.

Planned functions:

- Add checklist item.
- Edit checklist item.
- Delete checklist item.
- Change status: Not Started, In Progress, Done.
- Filter by category.
- Add optional notes.

Default categories:

- Banking
- Health
- Housing
- University
- Travel
- Other

用途：管理留学生活中的常见事项。

计划功能：

- 新增事项。
- 编辑事项。
- 删除事项。
- 修改状态：未开始、进行中、已完成。
- 按分类筛选。
- 添加备注。

默认分类：

- 银行
- 健康
- 住宿
- 学校
- 旅行
- 其他

## 3. Document Wallet / 重要文件夹

Purpose: keep local records of important documents.

Planned functions:

- Add document record.
- Upload an image or file.
- Preview an uploaded file when supported.
- Edit document title, category, expiry date, and notes.
- Delete document record.
- Store only local file paths or local file references in the first version.
- No cloud upload in the first version.

Possible document categories:

- Passport
- Visa / eVisa / BRP / residence permit
- Bank Letter
- University Letter
- CAS / admission document
- Tenancy Agreement
- Travel Insurance
- Student ID
- Other

用途：保存重要文件的本地记录。

计划功能：

- 添加文件记录。
- 上传图片或文件。
- 在支持的情况下查看文件预览。
- 编辑文件名称、分类、到期日期和备注。
- 删除文件记录。
- 第一版只保存本地文件路径或本地文件引用。
- 第一版不做云端上传。

可能的文件分类：

- 护照
- 签证 / eVisa / BRP / 居留许可
- 银行信
- 大学证明信
- CAS / 录取文件
- 租房合同
- 旅行保险
- 学生证
- 其他

## 4. Travel Planner / Travel Wallet / 旅行材料管理

Purpose: manage trip plans and travel documents.

Each trip can include:

- Trip name.
- Destination.
- Start date and end date.
- Notes.
- Flight ticket screenshots.
- Hotel booking screenshots.
- Visa / eVisa / insurance screenshots.
- A trip-specific checklist.

Planned functions:

- Add trip.
- Edit trip.
- Delete trip.
- Upload trip-related images or files.
- View files saved for a trip.
- Add, edit, delete, and complete travel checklist items.

用途：管理旅行计划和旅行相关材料。

每个旅行可以包含：

- 旅行名称。
- 目的地。
- 开始日期和结束日期。
- 备注。
- 机票截图。
- 酒店订单截图。
- 签证 / eVisa / 保险截图。
- 独立的旅行 checklist。

计划功能：

- 新增旅行。
- 编辑旅行。
- 删除旅行。
- 上传旅行相关图片或文件。
- 查看某次旅行保存的文件。
- 新增、编辑、删除和勾选旅行 checklist。

## 5. Budget Tracker / 生活预算记录

Purpose: record simple monthly living expenses.

Planned functions:

- Set monthly budget.
- Add expense.
- Edit expense.
- Delete expense.
- Show amount spent.
- Show remaining amount.
- Summarize by category.

Budget categories:

- Rent
- Food
- Transport
- Shopping
- Travel
- Subscription
- Other

用途：简单记录每月生活预算和支出。

计划功能：

- 设置月度预算。
- 新增支出。
- 编辑支出。
- 删除支出。
- 显示已花金额。
- 显示剩余金额。
- 按分类统计。

预算分类：

- 房租
- 餐饮
- 交通
- 购物
- 旅行
- 订阅
- 其他

## 6. Emergency Contacts / 紧急联系方式

Purpose: keep important contacts easy to find.

Planned functions:

- Add contact.
- Edit contact.
- Delete contact.
- Copy phone number.
- Copy email.
- Save notes such as opening hours or location details.

Contact categories:

- University emergency contact.
- Accommodation reception.
- Local doctor / GP phone number.
- Bank lost card number.
- Embassy contact.
- Local non-emergency police number.
- Friend or family contact.
- Other.

用途：保存重要联系方式，方便需要时快速查找。

计划功能：

- 新增联系人。
- 编辑联系人。
- 删除联系人。
- 复制电话号码。
- 复制邮箱。
- 保存开放时间、地点等备注。

联系人分类：

- 学校紧急联系方式。
- 宿舍或公寓前台。
- 本地医生 / GP 电话。
- 银行挂失电话。
- 使馆联系方式。
- 本地非紧急报警电话。
- 朋友或家人联系方式。
- 其他。

## 7. Search / 搜索

Purpose: search local records quickly.

Search should cover:

- Document names and notes.
- Checklist items.
- Trip names and travel notes.
- Budget records.
- Emergency contacts.
- General notes.

用途：快速查找本地保存的信息。

搜索范围应包括：

- 文件名称和备注。
- 生活事项。
- 旅行名称和旅行备注。
- 预算记录。
- 紧急联系人。
- 通用备注内容。

## 8. Language / 中英文切换

Purpose: support English and Chinese interface labels.

The first version should plan for:

- English.
- 中文.
- Translatable page titles, buttons, categories, and status labels.

用途：支持英文和中文界面文案。

第一版需要规划：

- English。
- 中文。
- 页面标题、按钮、分类和状态文案可以切换。

## Not Included In The First Version / 第一版暂不包含

Not planned:

- Login or registration.
- Cloud sync.
- Email templates.
- Community forum.
- Map search for local services.
- Official visa advice.
- Legal advice.
- Medical advice.
- Financial or immigration advice.

暂不计划：

- 登录或注册。
- 云端同步。
- 邮件模板。
- 社区论坛。
- 地图搜索本地服务。
- 官方签证建议。
- 法律建议。
- 医疗建议。
- 金融或移民建议。

## Possible Future Features / 后续可考虑功能

Possible later additions:

- Local notification reminders.
- Document expiry reminders.
- Subscription reminders.
- CSV / JSON export.
- App passcode lock.
- Dark mode.
- iCloud / Google Drive backup.
- Default checklist sets for different countries or regions.

后续可以考虑：

- 本地通知提醒。
- 文件到期提醒。
- 订阅扣款提醒。
- CSV / JSON 导出。
- App 密码锁。
- 暗色模式。
- iCloud / Google Drive 备份。
- 不同国家或地区的默认 checklist。
