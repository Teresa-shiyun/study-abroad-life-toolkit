# Privacy Notes / 隐私说明

## Local-First Plan / 本地优先计划

The first version is planned as local-only storage. It will not include login, cloud sync or shared accounts.

第一版计划只做本地保存，不包含登录、云端同步或共享账号。

## Sensitive Information / 敏感信息

Passports, visas, residence permits, bank letters, flight tickets, hotel bookings, insurance documents and student IDs are sensitive personal information.

护照、签证、居留许可、银行信、机票、酒店预订、保险文件和学生证都属于敏感个人信息。

Users should not upload real sensitive files to a public demo, and public screenshots must not show real personal information.

用户不应在公开 demo 中上传真实敏感文件，公开截图也不能展示真实个人信息。

## GitHub Demo Rules / GitHub 展示规则

GitHub README, screenshots and demo data should use:

- Fake names.
- Placeholder document images.
- Virtual passport or visa examples.
- Fake phone numbers and emails.
- Example travel files with no real booking details.

GitHub README、截图和 demo 数据应该使用：

- 虚拟姓名。
- 占位文件图片。
- 虚拟护照或签证示例。
- 虚拟电话和邮箱。
- 不包含真实预订信息的示例旅行文件。

## Not Advice / 非专业建议

The app should not provide visa, legal or medical advice. It can help users organise tasks and documents, but official decisions and professional guidance must come from universities, government websites, lawyers, doctors or other qualified sources.

这个 App 不提供签证、法律或医疗建议。它可以帮助用户整理事项和文件，但官方判断和专业建议应来自学校、政府网站、律师、医生或其他合格来源。

## Future Cloud Sync / 未来云端同步

If cloud sync is added later, the privacy and security design must be revisited before implementation. Possible topics include authentication, encryption, access control, backup, deletion, data residency and incident response.

如果未来加入云端同步，需要在实现前重新设计隐私和安全方案。需要考虑登录认证、加密、访问控制、备份、删除、数据存储地区和安全事件响应等问题。
