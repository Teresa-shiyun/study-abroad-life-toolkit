# Study Abroad Life Toolkit / 海外留学生活助手

## Overview / 项目简介

Study Abroad Life Toolkit is a planned mobile app prototype for international students. The first version is based on common UK student-life tasks, but the structure is kept general so it can later support other countries and regions.

海外留学生活助手是一个计划中的手机端 App 原型，面向海外留学生的日常生活管理场景。第一版会先以英国留学生常见事项为基础，但项目名称和信息结构保持通用，方便以后扩展到其他国家和地区。

This is not an information website, visa adviser, legal adviser or medical tool. It is a local-first toolkit for organising documents, life tasks, travel files, budgets and emergency contacts.

它不是信息网站，也不提供签证、法律或医疗建议。它的定位是一个本地优先的生活管理工具，帮助用户整理重要文件、生活事项、旅行材料、预算和紧急联系方式。

## Features / 功能概览

Planned first-version modules:

- Home dashboard for unfinished tasks, missing documents, budget usage and upcoming trips.
- Life checklist for student-life tasks such as banking, GP registration, SIM card and housing paperwork.
- Document wallet for local records of passport, visa, bank letter, university letter, tenancy agreement and student ID.
- Travel wallet for trips, uploaded ticket screenshots, booking files and travel checklists.
- Budget tracker for simple monthly spending records.
- Emergency contacts list with copyable phone numbers and emails.
- Global search across documents, checklist items, trips, budget records and notes.
- English and Chinese interface switching.

第一版计划包含以下模块：

- 首页总览：展示未完成事项、缺失文件、本月预算和即将到来的旅行。
- 生活事项清单：管理银行开户、GP 注册、SIM 卡、住房文件等留学生常见事项。
- 重要文件夹：本地记录护照、签证、银行信、学校信、租房合同和学生证等文件。
- 旅行材料管理：整理旅行计划、机票截图、酒店预订文件和旅行 checklist。
- 生活预算记录：记录每月基础花销和分类统计。
- 紧急联系方式：保存并复制重要电话和邮箱。
- 全局搜索：搜索文件、事项、旅行、预算记录和备注。
- 中英文界面切换。

## Privacy Notes / 隐私说明

- The first version is planned as local-only storage with no cloud sync.
- GitHub screenshots and demos must use fake data only.
- Do not use real passports, visas, bank letters, flight tickets or other sensitive files in public demos.
- If cloud sync is added later, privacy and security design must be revisited before implementation.

- 第一版计划只做本地保存，不做云端同步。
- GitHub 截图和 demo 只能使用虚拟数据。
- 公开演示时不要使用真实护照、真实签证、真实银行信、真实机票或其他敏感文件。
- 如果未来加入云端同步，需要在开发前重新设计隐私和安全方案。
